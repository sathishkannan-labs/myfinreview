# FinReview Community Edition v2.0.0 — Foundation Preview

> **Release classification: PRE-RELEASE / developer preview.** The existing Community Edition v1.0.0 remains the recommended hosted demo. The v2.0.0 preview is an opt-in code snapshot for developers and reviewers; **not a broker-connected production release**.

## What's included

- Provider-independent daily OHLCV model with timestamp, OHLC and volume validation.
- Optional FYERS and Upstox history adapters; optional Zerodha Kite Connect V3 historical candles and LTP quote adapter.
- Non-secret, user-scoped provider preferences for historical candles and quotes; no forced broker selection or obligation to open a new brokerage account.
- CSV validation-only import, account-isolated historical candle caching, duplicate detection, and explicit unverified-adjustment metadata.
- Deterministic breakout, ATR and moving-average research observations; opt-in WATCHING-only signal creation, expiry state machine and preliminary paper-ledger foundation.
- Read-only /v2 API and intelligence-dashboard preview.
- Operator-invoked, DRY-RUN-by-default Telegram report preparation for 09:00, 12:00 and 15:00 IST with explicitly approved trading dates and duplicate-send claims.
- Automated backend regression suite on Python 3.11 and 3.14.

## What v2.0.0 does **not** guarantee

- **No live broker connectivity is verified.** Broker credential authentication, per-user encrypted credential storage, token renewal, user entitlements and live quote streaming are not complete.
- Upstox live quote adapter is not implemented; current Upstox adapter is daily historical only.
- Zerodha Personal API does **not** include free historical or live market-data entitlements. Data-enabled paid Kite Connect access is required.
- No automatic hosted scheduler, verified NSE/BSE trading calendar, live Telegram delivery test, or deployed periodic ingestion.
- No production-ready backtesting or completed paper-trading accounting/performance engine.
- No completed production migration/rollback, staging security review, or replacement of the existing public hosted demo.
- The historical-data endpoint is OFF by default; do not enable a shared-token exchange-data proxy on a public multi-user deployment.
- **No real-money order execution.** Research signals are informational, not SEBI-regulated investment recommendations.

Do not point this preview at an existing production database without backing it up and validating the additive schema in staging. Keep broker tokens in secure server environment configuration, never in the GitHub repository or browser storage.
