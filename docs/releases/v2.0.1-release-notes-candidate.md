# v2.0.1 Community Edition — release candidate notes (NOT YET RELEASED)

This is a stabilization candidate built on the v2.0.0 Foundation Preview. It is **not** a stable GitHub Release; no `v2.0.1` tag should be created until all release gates are accepted.

## Included, user-facing

- Retains existing v1 portfolio, transaction, analytic and informational briefing workflows.
- Research Lab: authenticated upload of completed daily OHLCV CSV, strict validation, 20-bar close breakout and 20/50-day moving-average observations, historical context, downloadable JSON report.
- Explicit synthetic demonstration CSV, source/adjustment caveats, and research-only labels.
- Optional independent broker preferences (not authentication).
- Experimental paper-account/signal ledger clearly separated from finished user-facing research.

## Private developer-only broker validation

- Owner-only FYERS non-trading individual-app OAuth test, encrypted vault, read-only profile/historical/quote probes.
- **Actual staging evidence supplied by maintainer (15 Nov 2026):** authenticated FYERS profile, 5 completed daily bars for `NSE:INFY-EQ` during 8–14 Nov 2026, and a successful quote sample.
- The above test **does not** authorize public redistribution, certify quote timestamps, prove all instruments are entitled, or imply users can use the maintainer's FYERS app.
- Upstox and Zerodha providers have mocked adapter tests only and are **not certified live**.
- Never enable shared process-wide broker market proxies or accept public broker tokens. No real-money order execution.

## Stability and security changes

- User-scoped encrypted credentials and single-use, time-limited OAuth state; staging FYERS allowlist.
- Staging-only frontend/backend with a separate PostgreSQL database and independent secret configuration.
- Clear broker access status, local disconnect controls and safe failure messaging.
- Python 3.11 and 3.14 CI regression tests.

## Not included as completed Community features

Live broker-backed strategies for general users, brokerage trading, fully simulated fills and P&L, subscription market feeds, verified automatic signals, production scheduler, Redis/cache, provider-wide refresh/revocation, exchange-calendar certainty and guaranteed quote timestamps.

## Go/no-go acceptance required

1. Passing CI at frozen release commit.
2. Manual v1 regression: registration/login; portfolio, transactions, analytics, news; UI research CSV and report download.
3. Manual second-account access-denied test for FYERS; token expiration/disconnect and callback log hygiene.
4. PostgreSQL upgrade, backup and rollback drill; startup migration compatibility checks.
5. Security/PII and market-data licensing review, confirming FYERS individual-app mode remains owner-only and off by default outside staging.
6. Reviewed pull request to promotion branch, final post-deploy smoke test, then immutable stable `v2.0.1` tag/release. **Do not auto-publish before these checks.**

See `docs/releases/v2.0.1-live-test-readiness.md`.
