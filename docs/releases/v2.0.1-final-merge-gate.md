## Non-destructive acceptance snippets

Check status codes only; **do not paste bearer tokens or raw responses into GitHub, chat or logs**. Use separate normal-account credentials in a local secure test client. Without authenticated tokens a private route should return 401/403, not market data; this is a useful but **weaker** negative test.

To confirm an offline database backup, run `pg_restore --list /path/to/backup.dump` on a trusted machine. For a meaningful restore rehearsal, use a new disposable PostgreSQL instance and compare schema and row counts through privileged internal channels. Do not run destructive SQL on staging or production.
